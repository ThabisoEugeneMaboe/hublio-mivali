Turn ON Auto-Deploy for Mivali on Render
=========================================

Dashboard: https://dashboard.render.com/

1. Open service: hublio-mivali

2. Go to Settings (left menu)

3. Under "Build & Deploy":
   - Connected repository: ThabisoEugeneMaboe/hublio-mivali
     (If missing: Connect GitHub → authorize Render → pick this repo)
   - Branch: main
   - Auto-Deploy: YES (toggle ON)

4. Confirm:
   - Build Command: npm install
   - Start Command: node api/server.js
   - Health Check Path: /api/health

5. Save changes

6. Click "Manual Deploy" once now → Deploy latest commit
   (so Mivali logo goes live immediately)

After this, every git push to main on GitHub will deploy automatically.

Repo: https://github.com/ThabisoEugeneMaboe/hublio-mivali

Optional backup (GitHub Actions):
  Copy Deploy Hook URL from Render Settings → add GitHub secret
  RENDER_DEPLOY_HOOK_URL (see DEPLOY-TO-RENDER-NOW.txt)
